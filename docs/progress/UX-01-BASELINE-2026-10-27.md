## Scenario and timing method

The ignored integration target creates a mode-0700 `PANELINK_HOME`, starts the
real attach client on a private outer PTY, parses VT100 frames, and uses only
synthetic shell output. It tests outer sizes **24x100** and **40x120** with one
pane, 4,000 numbered history lines, 30 individual wheel-up events, a 20-event
burst, and 900 lines paced at approximately 10 ms per line. It then creates a
two-pane split for focus probes. Idle thumb measurements first click the
rendered thumb to resolve an unknown scrollbar extent; that preflight is not
timed. Output-load thumb measurements are not extent-preflighted.

Latency starts immediately before the SGR input write. First change is the first
parsed change to the pane's interior cells; settled is 65 ms without another
interior-cell change. Samples are polled from the private-PTY reader/parser.
These values combine input delivery, client/server work, rendering and PTY
observation; they do not separate read round-trip from host paint. Percentiles
use linear interpolation; burst and drag measurements have one observation.

## Observed interaction behavior

- Idle thumb drag: pane interior did not change before release on either host;
  after release the first change was about 19–20 ms. This agrees with
  seek-on-release for a primed, known range.
- Thumb during output: interior cells changed before release, with no separate
  post-release change sample. Because the range was not preflighted while output
  continued, an unknown-extent seek may be included; do not infer continuous
  thumb seeking from this observation.
- Reading position during output: no interior-cell drift observed over the
  250 ms sample interval on either host.
- Focus: after first marking the left pane as focused, wheel interaction and
  thumb interaction on the right pane both caused the next shell marker to
  appear outside the left pane (`wheel_kept_focus=false`,
  `thumb_kept_focus=false`) on both host sizes.
- Cleanup: each client detached and restored outer-PTY termios; the private
  server lock was released before the fixture directory was removed.
