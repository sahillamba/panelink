## Observed source behavior

Reviewed downloaded Crossterm 0.29.0 sources with graph-first symbol discovery. A Luna xhigh reviewer reported findings but hit its usage limit before producing a finished document; the parent inspected the decisive source paths and wrote this checkpoint. [Source fingerprints](p2-core-review/host-source.json) identify the reviewed files. These observations do not represent a scoped security audit of the entire library.

- `src/event/source/unix/mio.rs`, `Parser::advance` (198–220): every incomplete sequence byte is pushed into a `Vec`; capacity 256 is an initial allocation, not a limit. The alternate `tty.rs` parser has the same buffering pattern. The ordinary Unix `events` path uses Mio; `use-dev-tty` changes the backend.
- `src/event/sys/unix/parse.rs`, `parse_csi_bracketed_paste` (813–823): waits for the closing `ESC[201~`, then converts the retained payload with `String::from_utf8_lossy(...).to_string()`. Raw-frame storage is unbounded before application paste rejection; invalid UTF-8 can also expand during conversion. A check only on `Event::Paste` is too late.
- `mio.rs`, `EventSource::try_read`: its inner read loop neither exits on `Ok(0)` nor propagates errors other than its explicit WouldBlock/Interrupted branches. The timeout check occurs after that inner loop. Continuous incomplete input, EOF or a persistent hard error can prevent bounded return. This is a source finding, not a reproduced runtime hang. `FileDesc::read` delegates to the OS read; descriptor blocking behavior and raw-mode settings need explicit review in the selected host path.
- `src/event/read.rs`, `InternalEventReader::poll`: filtered-out events accumulate in `skipped_events`, then extend `events`; neither queue has a fixed cap. The read path has additional skipped-event storage. A finite poll timeout alone does not bound retained queues across calls. Avoid cursor/keyboard negotiation or another internal filter as a workaround; the selected path must account for every queue.
- The SIGWINCH branch calls `terminal::size`; `src/terminal/sys/unix.rs` can fall back to a `tput` subprocess. A resize path must instead use a reviewed ioctl-only query with explicit failure behavior.

## Next implementation gate

First choose and specify one bounded adapter inside the existing upstream parser, rather than adding a Panelink escape parser. Review the complete selected feature graph, notices, maintenance, advisories and build inputs before application adoption. A local correction must have a distinct version, preserved upstream notices, full patch and fingerprints, as with the selected VT100 core. Do not add the original candidate's default/event-stream/async feature set merely to obtain input decoding.

The correction design must establish all of the following before a host probe:

1. Check incomplete control storage **before push/allocation**, with a 16 KiB ordinary-control ceiling. Bound a framed paste to at most 65,536 payload bytes plus its 12 framing bytes, and separately bound converted UTF-8 bytes before allocation. The core may reject a framed child paste whose complete encoding exceeds its 64 KiB input queue. Reject invalid UTF-8 atomically or prove the expansion bound; do not silently send a prefix.
2. On oversized/malformed host input, fail the probe visibly and close its input path through terminal restoration and bounded child cleanup. Clearing a paste buffer and treating its remaining bytes as keystrokes could execute a rejected paste suffix; that behavior is forbidden. Fail-closed termination avoids needing a new discard parser. Never log the bytes.
3. Set explicit per-call byte/work and monotonic time limits, including incomplete sequences and repeated Interrupted reads. Return promptly on EOF/hard error. A timeout cannot depend on eventually completing an input event. Keep a fixed event/byte budget across source, filtered and application queues; finite event count alone is insufficient if each event owns a large paste.
4. Review ownership of stdin or an explicitly opened TTY, descriptor flags, raw termios, signal registration and global readers. A duplicated descriptor shares status flags with its source; save/restore any changed flags on constructor failure, exit and panic. Use one event reader, no hidden cursor queries or size subprocesses. Fail before raw mode on redirected/non-TTY host IO for this prototype unless an explicit supported path is specified.
5. Keep a separate scoped host guard that restores termios, flags, cursor, styles, alternate screen and host bracketed-paste mode after ordinary exit, error and unwind. Host output must be generated from snapshots only. Render at cell boundaries: snapshot control replacement can turn zero-width formatting characters into visible replacement scalars, so printing each cell's whole string consecutively is not a width proof. Combining, wide continuations and bottom-right wrapping require explicit renderer tests.

Proposed verification is unrun: fixed-storage overflow cases split at every delimiter boundary; incomplete CSI and missing paste terminator; invalid UTF-8 expansion; oversized paste followed by a harmless command-shaped suffix (no suffix event); filtered-event floods; injected EOF/read errors/Interrupted loops; bounded per-call progress; non-TTY rejection; ioctl-only resize failure; and an outer-PTY harness checking termios/flags/restoration after ordinary quit, renderer failure and panic. Then run the Apple Terminal checklist in [P2-EXPERIMENT.md](P2-EXPERIMENT.md), including actual shell/vi/Unicode/paste behavior. The host graph and these runtime gates remain incomplete.

## Parser-only correction task

The next bounded implementation is now specified in [P2-DECODER.md](P2-DECODER.md): extract only the selected upstream parser/types into a distinct MIT component, with one fixed input buffer and no event queue or upstream IO backend. The application host loop and terminal guard remain separate from the global reader/filter framework. [P2-RENDER.md](P2-RENDER.md) specifies the independent pure snapshot renderer. These component tasks do not establish host IO/restoration or a running terminal UI.

Additional source finding from the Luna reviewer: neither selected Crossterm Unix host reader sets O_NONBLOCK on its TTY; the alternate backend's nonblocking calls apply to its wake pipe. `tty_fd()` borrows terminal stdin or separately opens `/dev/tty`. The Mio constructor registers that descriptor without changing flags. Consequently a read-until-WouldBlock path on a blocking descriptor can block after consuming available raw input; its poll timeout is not a host progress bound. A future Panelink host path must use explicitly nonblocking owned IO. Prefer a separately opened `/dev/tty` to avoid changing status flags shared by a duplicated standard descriptor, and still save/restore exact terminal termios on all exit paths. No such host path is implemented in this checkpoint.

Latest implementation checkpoint: the selected decoder, pure renderer and original owned-TTY loop now satisfy the reviewed source boundaries. signal-hook0.4.5 defaults=false supplies process-lifetime atomic flags only (P2-SIGNALS-REVIEW.md). The broad runtime criteria above remain acceptance requirements, not passed checks; no complete Crossterm host framework was adopted. See latest INTEGRATION.md and ROADMAP.md before resuming.
