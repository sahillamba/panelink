Public TargetRef (Copy/Eq/Debug) has generation, workspace, pane, session, occupant_revision: u64. ControlRequest<'a> (Copy/Eq) has public key: crate::protocol::OperationKey, target: TargetRef, command: Command<'a>. Public ReadSource enum Screen and LiveScrollback. Public Command<'a> variants Read{source,max_bytes:u32,max_lines:u16}, Text{owner_revision:u64,text:&'a str}, Paste{owner_revision:u64,text:&'a str}, Submit{owner_revision:u64,text:&'a str}, Interrupt{owner_revision:u64}. Custom redacted Debug for Command and ControlRequest includes only numeric IDs/operation kind/length metadata, never text. class() maps Read to Query, Text/Paste/Submit to Input, Interrupt to Signal; no automatic-retry meaning is introduced. Use existing OperationClass/OperationKey, no duplicate types.

Public constants CONTROL_SCHEMA_VERSION:u16=1, MAX_INPUT_TEXT_BYTES:usize=32768, MAX_READ_BYTES:u32=65536, MAX_READ_LINES:u16=1024. These are prototype schema limits, not runtime capability promises. All multibyte fields big endian. Request payload fixed prefix68bytes: schema u16=1 (offset0), opcode u16 (offset2), key generation/lease/sequence as three u64 (offset4,12,20), target generation/workspace/pane/session/occupant_revision five u64 (offset28,36,44,52,60). Opcodes1 Read,2 Text,3 Paste,4 Submit,5 Interrupt. No other opcode accepted. Key and all target fields nonzero; key.generation == target.generation. All public forged values revalidated before encoding.

Body Read: source u8 (1Screen,2LiveScrollback), max_bytes u32 in1..=65536, max_lines u16 in1..=1024; total75bytes. Body Text/Paste/Submit: owner_revision u64>0, byte_len u32, then exactly byte_len UTF-8 bytes; total80+byte_len. All text variants cap32768 UTF-8 BYTES, empty is valid; Text and Submit reject Unicode control scalars (literal printable text profile; Enter is Submit's declared effect); Paste permits caller-supplied valid UTF-8 contents under the reviewed paste boundary. No newline addition/terminal encoding in this codec. Body Interrupt: owner_revision u64>0; total76bytes. Decode rejects trailing bytes, unsupported schema/opcode/read source, truncated numbers/body, invalid UTF-8/controls/limits/nonzero fields/generation mismatch, and payload above65536 before parsing. Use checked lengths before slicing; no production Vec/String/payload allocation, unbounded loops, serialization libs, or error messages containing bytes. UTF-8/control scans bounded by32768bytes.
