# Host component adoption review — 2026-10-17

Decision: parent approves `crossterm-input` version `=0.29.0-panelink.1`, local `vendor/crossterm-input`, for the disposable prototype's **pure raw-input decoding component**. This is a selected MIT third-party parser extraction, not independently written Panelink escape grammar or an upstream Crossterm release. It includes no global event reader, Mio, signals, terminal commands, subprocess fallback or clipboard API. Host IO/restoration, CLI probe and Apple Terminal compatibility remain unimplemented.

## Selection and source review

Reusing the established Unix key/mouse/paste parser avoids independently implementing escape grammar. The selected source subset replaces the rejected unbounded reader with a fixed-buffer stream adapter inside that component. A scoped extraction has a smaller runtime/build graph than adopting and correcting the whole global event framework. The cost is a second local third-party variant that Panelink must maintain and re-review before release. This decision applies to the personal feasibility prototype, not the firm's unknown approval process.

Upstream: [Crossterm](https://github.com/crossterm-rs/crossterm) 0.29.0, MIT Copyright 2019 Timon, archive SHA-256 `d8b9f2e4c67f833b660cdb0a3523065869fb35570177239812ed4c905aeff87b`, VCS `36d95b26a26e64b0f8c12edfe11f410a6d56a812`. The archive hash matches the published crates.io checksum; preserved parser/event/license originals match the downloaded registry source byte-for-byte. See [extraction/provenance](../../vendor/crossterm-input/PROVENANCE.md), [full patch](../../vendor/crossterm-input/PATCH.diff) and [fingerprints](../../vendor/crossterm-input/FINGERPRINTS.json). No upstream generator or installer ran. Original notices are also under `third_party/licenses/crossterm-0.29.0/`.

Parent inspected the normalized parser/type deltas and stream adapter. Changes are: extraction/module paths and raw-input-only constant; fixed 65,548-byte boxed storage with a 16,384-byte ordinary sequence ceiling; pre-store cap checks; paste payload/UTF-8 validation before String allocation; permanent failure with no suffix reinterpretation; direct single-event return with no queue; discarded internal responses; checked coordinate subtraction; and redacted input Debug. One pending ESC is resolved only through the existing parser after a caller timeout. No new escape grammar or IO is added to Panelink.

Recognized internal response parsing remains permissive (including an upstream device-attributes stub); those events are discarded. This is not a claim to reject every noncanonical sequence. Parsing/storage per call is bounded by the selected sequence caps, but no host scheduling deadline is measured. The future loop must check byte/work/time limits, enable raw mode before using this parser, stop immediately on error and restore the host. See [task contract](P2-DECODER.md) and [candidate result](P2-DECODER-RESULT.md).
