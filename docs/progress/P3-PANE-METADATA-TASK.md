# Phase 3 managed-child metadata contract

Accepted bounded engineering slice, 2026-10-23. Full Phase 3 remains open.

Query the current direct managed child's cwd/executable; never substitute launch paths or infer foreground descendants. These independently sampled paths are private live Read-authorized observations, never argv/env, persistence, history or diagnostics. Paths are absolute UTF-8, no NUL/control characters, at most4095 bytes each; otherwise explicit unavailable. No truncation or lossy conversion. Debug redacts paths/identity. Sample time is generation-relative monotonic milliseconds, not an atomic pair or freshness guarantee.

Schema12, optional capability16 PANE_METADATA, available only on the multi-session server. Existing schema10 pane replies unchanged. Query48 bytes: schema u16BE at0=12, kind u16BE at2=1, reserved4..8 zero, full TargetRef five u64BE at8..48 (generation/workspace/window/pane/session). Reply72-byte prefix: schema12, kind0x8001, reserved4..8, target8..48, sampled_at_mono_ms u64BE48..56; cwd status56, executable status57; reserved58..60; cwd length u16BE60..62, executable length62..64; reserved64..72; then cwd and executable bytes. Maximum8262 bytes. Status1 available,2 exited,3 permission_denied,4 process_gone,5 invalid_path,6 query_failed,7 timed_out,8 unsupported,9 identity_mismatch,10 busy. Only available has a nonempty path; unavailable lengths zero. Strict lengths/reserved/target/status validation.

Public codec API: PathStatus enum variants above, PathObservation{pub status:PathStatus,pub value:Option<String>}, PathObservation::unavailable(status), PathObservation::available(String)->Result<Self,MetadataError>, Observation{pub target:TargetRef,pub sampled_at_mono_ms:u64,pub cwd:PathObservation,pub executable:PathObservation}, Observation::unavailable(target,time,status); encode_query(target)->Result<Vec<u8>,MetadataError>, decode_query(&[u8])->Result<TargetRef,...>, encode_observation(&Observation)->Result<Vec<u8>,...>, decode_observation(&[u8])->Result<Observation,...>. No I/O in codec.

Native source gate: existing libc0.2.191 lacks libproc declarations; no new dependency. Narrow reviewed system libproc FFI is allowed for macOS/aarch64 only. Local SDK declarations proc_pidinfo/proc_pidpath, PROC_PIDTBSDINFO3 and PROC_PIDVNODEPATHINFO9. Parent C ABI probe compiled with -Wall -Wextra -Werror reports bsd136, pid offset12, birthsec120/birthusec128; vnodepath2352, cwdpath offset152 length1024; exe buffer4096. Require exact struct byte counts. SDK-derived aligned opaque initialized buffers avoid duplicating larger headers. Capture PID/birth immediately after spawn; query before/after birth and reject mismatch. Failed capture never fails launch. Worker owns no child/PTY/storage lock. Fixed queue/completion cap1; one active query; finite500ms owner deadline, busy while late native work persists. Owner authorization/full-target/current identity revalidated before publication. No kernel cancellation claim.

CLI keeps cwd and command fields (command is executable path only), adds metadata_source=managed_child, sampled_at_mono_ms, cwd_status and command_status. A dedicated optional metadata context requests READ|PANE_METADATA; older servers/grants return unsupported without widening old grants. Layout revision remains checked around pane list, no atomic metadata/layout promise.

Acceptance: strict malformed/privacy codec cases; native cwd chdir and direct exec, descendant distinction, identity/race/error paths; worker isolation/timeout; authorized exact target and denied/stale cases; integration CLI JSON and no args/env leakage. Parent reviews all workers and runs appropriate verification. No phase-completion commit or push implied.
