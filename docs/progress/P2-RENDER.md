# Snapshot renderer task

One owner may edit only `src/terminal/render.rs` and `docs/progress/P2-RENDER-RESULT.md`. Parent owns module export, manifests, roadmap and all other files. Read ROADMAP.md, P2-CORE.md, P2-HOST-INPUT.md and this contract first. Match existing Rust style; graph-first code exploration; no commits/pushes or ms-rust compliance claim. Do not change the core/snapshot or create a host terminal guard, CLI or input decoder in this task.

Parent approves direct use of existing exact `unicode-width = 0.2.2`: already enabled by the selected engine, reviewed/licensed/inventoried. This adds no package, feature or build script. No other dependencies.

Implement `pub fn render<W: std::io::Write>(snapshot: &super::ScreenSnapshot, host_rows: u16, host_columns: u16, output: &mut W) -> std::io::Result<()>`. Reject a host viewport smaller than the snapshot before any write. This is a pure bounded snapshot-to-output function, not host compatibility or restoration evidence. Own no global IO, state, strings, previous frames, history or event queue. Stream output without building a frame String/Vec. Debug/errors must not contain screen text. Propagate the first write error; never swallow it or retry a whole frame. A later host guard must restore modes on partial output failure.

Render only trusted numeric/constant host controls and validated snapshot cell scalars. Begin with hide cursor, disable autowrap, reset SGR and erase screen. For each non-continuation cell emit absolute one-based cursor position and a fresh SGR reset plus only snapshot bold/dim/italic/underline/inverse and typed foreground/background (Default, indexed, RGB). Never emit title, hyperlink, clipboard, queries, raw child bytes or upstream formatted-screen output. Render blanks as spaces so backgrounds are covered. End with SGR reset, snapshot cursor clamped to visible dimensions, autowrap enabled, and show cursor only if child cursor is visible. A future host guard also restores autowrap on error/panic. Hosts must support these reviewed basic ANSI controls; that is an untested assumption until the outer-PTY/Apple Terminal gate.

Position each rendered cell independently. Emit a wide cell only if it has a matching continuation within the same row; skip that continuation. Use `UnicodeWidthChar::width` to require the first scalar's width to match the engine's expected cell width (1 or 2), and subsequent scalars to have width zero. Reject controls/bidi/separators again at output. If the cell text is invalid for this width (including multiple visible replacements created by sanitization, missing base, or an orphan wide/continuation flag), render a fixed ASCII `?` with space padding to the occupied cell width; never spill multiple visible replacements across cells. Empty ordinary cells render one space. Orphan continuations render a blank at their assigned column. This conservative fallback does not promise grapheme/emoji/font width equivalence; record the limitation for manual testing. Disable wrap while rendering the bottom-right cell; do not emit newlines.

Tests must use actual engine-derived snapshots and synthetic private snapshot canaries where necessary: malicious OSC52/title/control/bidi/separator content never produces child-origin controls; ordinary Unicode/base+combining and matched wide cells survive; width-expanding replacement cells use fallback, with independently positioned following cells; orphan/wide-at-right-edge fallback; cursor/mode/style/color output; undersized viewport rejects before output; injected writer failure propagates; maximum 80x240 snapshot streams a finite frame without retained output (counting sink, conservative <=4 MiB output). Do not claim terminal restoration from these pure tests.

## Incremental rendering amendment — 2026-10-17

The original full-render function above remains available for initial/invalidated frames. Following operator-reported full-screen reload on each change, render_diff now accepts an optional caller-owned prior snapshot and emits only changed cells/cursor for stable viewports. Wide-cell footprint changes conservatively repaint their row. The binary host owns two preallocated snapshot caches, advances the displayed baseline only after complete output acceptance, and invalidates on resize/discard. No frame history or raw child controls are retained. See P2-DELTA-RESULT.md for tests and integration evidence. This supersedes the old no-previous-frame host assumption, while the pure renderer itself retains no state.
