# Experimental host probe implementation contract

Prototype scope: one disposable child, one owned host TTY, no daemon/reconnect/persistence. Implementation is for macOS/aarch64 only. Child exit or explicit probe exit stops/reaps the child; this does not change product server lifetime. No handwritten parser or signal/terminal FFI. Use the selected decoder, core, renderer and reviewed Rustix wrappers. Signal dependency adoption must be recorded by the parent before use. No commits/pushes; no ms-rust compliance claim.

## Binary-private interface and launch

`src/main.rs` declares `mod p2_probe` only on `all(target_os="macos", target_arch="aarch64")`. It calls `p2_probe::run(&ResolvedLaunch, &[OsString], &Environment) -> Result<ProbeExit, ProbeError>`. Types are `pub(crate)`. `ProbeExit::{Child(std::process::ExitStatus), Quit, Interrupted}`; CLI maps child code or 128+signal, Quit to0, Interrupted to130. Probe errors have stable labels/categories only, no caller paths/argv/env/input/screen text. This is a process-entrypoint-only, one-shot runner; it is not an embeddable terminal library.

CLI syntax: `panelink pty-probe --terminfo <absolute-directory> -- <executable> [arguments...]`. Require exactly this prefix and nonempty executable. Malformed syntax exits2 before host side effects. Do not print arguments or environment. Non-supported targets fail with a fixed unsupported message and exit1. Existing help/version exit0, doctor remains1 (persistent multiplexer unsupported), unknown args2. Help and doctor truthfully describe the available experimental probe and remaining unsupported runtime.

Require an existing absolute terminfo directory containing a regular compiled `p/panelink-probe` or `70/panelink-probe` entry. Do not compile/install terminfo or choose a fallback subprocess at runtime; README supplies the explicit operator `tic` command. Existence is not a terminfo-conformance/security guarantee. Canonicalize directory. Capture current_dir and current client vars_os once into LaunchContext; never mutate process-global environment. Profile caps: <=4096 variables and <=1 MiB total name/value bytes, <=256 child args and <=64 KiB total executable/argument bytes. Reject overflow before adding more items; no diagnostics include values. Use existing build_environment with empty account defaults, no override layers, owned TERM=panelink-probe and TERMINFO=provided directory. Use resolve_launch(executable, Path::new("."), context, built environment). Keep map volatile; no persistence/provider logic. Core performs its own forged-input validation. Drop redundant context/maps before running if possible.

## Host resource lifecycle

Before terminal changes or child spawn: verify both stdin/stdout are TTYs; separately open `/dev/tty` RDWR|NONBLOCK|CLOEXEC through safe reviewed wrappers, save exact termios, query size via tcgetwinsize only. Never change standard-descriptor flags or use a dup as a new open-file description. No host queries, tput, clipboard APIs or extra process. Reject dimensions below5x20 or zero; clamp larger host size to at most80x240 for the core, retaining actual dimensions for renderer validation. Allocate decoder, fixed 1024-byte read chunk and one fixed3MiB heap output buffer plus two maximum-capacity sanitized snapshot caches before spawn. No growing frame Vec/String or event queue. Frame writes use a cursor into that fixed slice; overflow is a named error.

Signal handling is process-lifetime and flag-only: after preflight and before raw mode/child spawn, register SIGTERM/SIGHUP/SIGINT to one Arc<AtomicBool> using the parent-approved signal-hook0.4.5 defaults=false. Registration failure exits before terminal mutation/spawn. Do not unregister in cleanup/Drop: registry unregister can spin without a bound and does not restore dispositions. Flags/handlers intentionally live until main exits immediately after run returns. One-shot entry prevents reentry (return a named error); do not clear/reuse old flags or expose this as a reusable library guard. No iterator/self-pipe/thread; handler does only reviewed atomic-store work. SIGKILL, abort and fatal/unhandled signals cannot restore the host and remain limitations. Scope these statements honestly in docs/tests.

Create core TerminalSession with initial checked dimensions and explicit launch map, then aggregate host+session in a resource owner BEFORE enabling raw mode. It must implement Drop that attempts host restoration FIRST, then bounded cached session shutdown. No panic path can strand a raw host while waiting on child cleanup. Enter raw using saved termios clone + make_raw and tcsetattr(Now), not Drain. Mark restoration responsibility before the first mutation. Enter alternate screen, hide cursor, enable host bracketed paste; only constant trusted controls. Setup writes and restoration writes must have finite nonblocking budgets (100ms each), retry partial prefixes only within that live operation; Interrupted/WouldBlock must not create an unbounded loop. Restore with a constant sequence resetting SGR, autowrap, host bracketed paste, cursor and alternate screen, and always attempt saved tcsetattr(Now) even if output fails. Cache cleanup so explicit cleanup+Drop cannot repeat deadlines. Flush already-queued host input with tcflush(IFlush) before/after termios restoration; do not use the potentially output-draining TCSAFLUSH action. Keep the owned TTY until child cleanup finishes, flush queued input once more, then close. This prevents already-buffered rejected input from returning to the outer shell; the process cannot suppress bytes an external producer sends after its final flush/exit. Exact saved termios/unchanged standard flags are distinct from ANSI visual modes, which reset conservative defaults because prior private modes are not queried. Preserve/report restoration failure even if another body error occurred. Child shutdown keeps existing HUP1s/KILL1s contract. No blocking wait/read/write/flush or unbounded output drain; OS scheduling/ioctl time is not a hard realtime promise.

## Bounded loop

Every turn checks stop flag and makes at most one core pump. Read at most1024 host bytes nonblocking when no previous chunk suffix is pending. Process at most1024 bytes and check a monotonic5ms input-work budget between decoder calls; retain only unread suffix in that same fixed chunk. All bytes use decoder.advance(..., true), never a raw host-to-child byte path. On error, stop immediately; never interpret a rejected paste suffix. Each newly pending sequence must receive a timestamp even after an earlier key completed in the same read chunk; completed events cannot erase timing for the next prefix. Keep reading local quit input during child-exit draining, while ignoring InputDisabled at the child boundary. A pending lone ESC resolves via finish_escape only after50ms with no new bytes and no unread chunk suffix. Other incomplete controls/paste fail after2s of input inactivity; no timeout flush/reinterpretation. EOF/hard host read errors stop through the same cleanup path; Interrupted/WouldBlock defer. No continuous-input starvation of core/output/resize/stop checks.

Handle Event::Key Press/Repeat only: empty/Shift printable characters to Key::Char, plain Enter/Tab/Backspace/Esc/arrows/Home/End to corresponding typed core key, Control-c to Interrupt, Control-x to explicit probe Quit (Control-q remains a compatibility alias). Ignore other recognized keys/modifiers, releases, mouse/focus/resize events; document this narrow profile (Ctrl-D and Alt/function shortcuts are not forwarded yet). Event::Paste goes only to core.paste and is dropped immediately after admission; no application event queue, partial paste or retry. Queue rejection fails visibly after cleanup.

Query host dimensions by ioctl at most every100ms. Coalesce checked core resize and commit only through core.pump; renderer uses latest actual viewport. A resize below minimum fails cleanly. After observing resize, discard stale host-frame suffix and redraw from current snapshot after accepted dimensions update; only trusted renderer bytes are discarded, never child input. An ESC-prefixed new frame/reset cancels a partially emitted trusted control; document possible partial glyphs until redraw. Do not discard core terminal state or query replies.

Retain at most one output frame in the fixed3MiB slice. Render only when dirty and no pending frame, at most every50ms; dirty is set by output, successful size change and initial state. Render differences into the bounded slice against the last fully accepted frame. Copy the target into a preallocated cache before rendering; only swap it into the displayed baseline after the final output byte is accepted. Identical frames produce no output. Resize/discard invalidates the baseline, including resizes that keep the clamped core dimensions unchanged; the next frame fully repaints. Flush at most64KiB through one nonblocking write attempt per turn, consuming only accepted prefix. WouldBlock/Interrupted defer; zero write/hard error stops, and no progress for1s is OutputStalled. New terminal state remains in the core while a frame drains. On child exit+PTY EOF, build/flush the final dirty frame before cleanup with a1s overall final-frame deadline; do not wait indefinitely. Explicit quit/error may discard remaining trusted host output. Sleep at most5ms between turns. Polling measurements are not a guaranteed scheduling latency.

## Parent integration review notes

The fixed host frame is 3,145,728 bytes; one snapshot is at most 1,228,800 bytes, and the decoder plus one live paste is below 132 KiB. Retained launch data is capped at 1 MiB of environment strings, 4,096 entries and 64 KiB argv bytes. Preparation temporarily holds the client/final map, while core spawn temporarily copies the final map/argv into `Command`; the client context is dropped before core allocation/spawn and `Command` is dropped immediately after spawn. Allowing 8 MiB for these bounded string copies, tree nodes, C-string/pointer conversion and path/argument metadata keeps the shared snapshot/host/launch allowance below the original 20 MiB. Two render caches add at most 2,457,600 bytes to the core snapshot; together with the fixed frame, <=132 KiB decoder/paste and 8 MiB launch allowance, the shared allowance stays below 20 MiB (under 15 MiB using these component ceilings). Cache storage is allocated before spawn and reused across viewport changes; no event/frame queue or growing output buffer is retained. This is source accounting under the existing Rust 1.99.1/macOS limits, not a measured process RSS bound; inherited process/runtime state and child memory are outside that allocation model.

Runtime diagnostics must also obey the output deadline. After `run` fails with TTY stdin/stdout, use a separately opened nonblocking `/dev/tty` for a fixed, sanitized diagnostic with a 100 ms deadline; do not fall back to potentially blocked inherited stderr. If the sink cannot be opened/written, return failure status without a message. Non-TTY preflight errors may use ordinary stderr before any child/raw-mode side effects. No standard-fd flags are changed for reporting.
